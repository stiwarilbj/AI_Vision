- `01-capture.jpg` — Capture mode with the empty question field
- `02-settings.jpg` — Settings with a locally saved Gemini key (the key is masked)

The images are kept as source captures for a listing-only update. They do not depict the unreleased GitHub-build v2.8 preview and contain no real key or private content.
