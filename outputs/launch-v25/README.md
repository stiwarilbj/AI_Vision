# AI Vision v2.5 community launch kit

These assets promote the public **v2.5** Chrome Web Store build. The GitHub repository also contains a v2.8 preview, but these launch files do not describe preview-only controls as if they were published.

## Files

- `01-select-capture.png` — public-flow selection screen, 496×732.
- `02-answer-follow-up.png` — answer and follow-up state, 430×735.
- `03-copy-text.png` — image-to-text example, 430×800.
- `ai-vision-v25-demo.webm` — 24-second captioned demo made from the prepared interface captures.
- `community-drafts.md` — one distinct draft for each approved community.
- `launch-log.md` — baseline, publication checklist, and day-7/day-14 review template.
- `hn-human-notes.md` — a factual brief for a human-written Show HN submission; no generated HN post is included.

All responses shown in the images and demo are illustrative. No API key is included. The public install requires the user’s own Gemini API key from Google AI Studio.

## Posting checklist

1. Verify the live website and Store listing before posting.
2. Choose the community’s self-promotion flair where required.
3. Publish at most one post per destination, using the destination’s canonical link and no tracking parameters.
4. Keep the post open for genuine questions about setup, restricted pages, and API limits.
5. Record the resulting URL, publication time, visible views, and engagement in `launch-log.md`.
