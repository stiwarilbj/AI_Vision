Privacy notice

Last updated: August 27, 2026

AI Vision – Gemini Screenshot & Browser Assistant is a Chrome extension that lets a user ask Google's Gemini API about a selected screenshot, The Tab, or supported tabs in one Chrome window. Its optional Agent Mode can perform a limited browser task within the scope selected by the user.

Data AI Vision handles

Only when a user invokes a feature, AI Vision may handle the user's question, response-style choice, selected model, selected screenshot, visible webpage text, page titles and URLs, visible interactive-element labels or destinations, content from up to 20 supported tabs in the starting Chrome window, the user's Gemini API key, and locally saved preferences.

AI Vision reads live tab information needed for The Tab, All Tabs, and Agent Mode. It does not read the user's saved Chrome browsing-history database. Page text, labels, URLs, screenshots, and Google ADK plans are untrusted input and cannot authorize an extension action.

Use and sharing

AI Vision uses this information only to provide the feature the user requested. The prompt and necessary screenshot or webpage context are sent directly from the extension to the Google Gemini API over HTTPS. The Gemini API key is sent to Google in the x-goog-api-key request header so Google can authenticate the request.

AI Vision has no developer-operated analytics, advertising, tracking, or proxy server. The developer does not sell or rent user data. Data sent to Google is handled under Google's applicable Gemini API and privacy terms.

Storage and retention

The Gemini API key and user preferences are stored locally through chrome.storage.local in the user's Chrome profile. The service worker is the only runtime component that reads the full key; the panel receives only masked status. AI Vision does not intentionally store screenshots, page content, prompts, Gemini responses, or browser-task context on a developer server. Users can remove locally stored extension data by clearing the extension's data or uninstalling it.

Agent Mode controls

Agent Mode is off unless the user enables it. The bundled Google ADK browser runtime runs inside the service worker and sends bounded planning context directly to Gemini using the key saved in AI Vision Settings. Capture and The Tab stay in the source tab; All Tabs and newly opened tabs stay in the starting window. Every task stops after 12 steps. Reading, waiting, scrolling, and existing-tab activation can proceed automatically; clicks, text entry, navigation, new tabs, history movement, and reload require explicit approval. Sensitive and consequential actions remain blocked.

Permissions

activeTab supports user-initiated access to the current page. Gemini and the bundled ADK runtime use a narrow Google host permission. Optional tabs and ordinary HTTP/HTTPS host access are requested only when the user chooses All Tabs. Chrome internal pages, the Chrome Web Store, and other restricted pages are not accessible.

Remote code

AI Vision does not use remotely hosted executable code. Its JavaScript and CSS are packaged with the extension. Gemini API responses are treated as data and are not evaluated, imported, or executed as code.

Limited use

AI Vision's use and transfer of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide or improve prominent user-facing features and for security or legal compliance where required.
