Follow the key setup guide →

  1. Add AI Vision to Chrome

    Install from the Chrome Web Store, then pin AI Vision from Chrome’s Extensions menu.

  2. Get your key from Google

    Sign in to AI Studio. Copy an existing key, or choose Create API key. New users may already have a default key after completing Google’s setup.

    Open Google AI Studio ↗

  3. Paste it in AI Vision

    Open the extension’s Settings, paste your key, and save. Then select a screenshot and ask your first question. Google controls API limits and any charges.

Good to know

Small tool.
Clear boundaries.

Your key stays in Chrome. Requests go directly to Google. Optional browser tasks keep their approval and Stop controls.

Read the privacy notice →
Do I need a Gemini API key?

Yes. AI Vision uses your own key from Google AI Studio. Save it in the extension’s Settings. The website never asks you to paste a key.

Is AI Vision free?

The extension is free to install. Google controls Gemini API pricing, model availability, and usage limits. Check the limits and billing for your project in Google AI Studio.

What gets sent to Google?

Your question and the screenshot or page context needed for the request go directly to the Gemini API. Your key stays in Chrome’s local extension storage and is sent to Google to authenticate requests. There is no developer proxy or analytics.

Does it work on every page?

AI Vision works on supported webpages. Chrome internal pages, the Chrome Web Store, and other restricted pages cannot be analyzed. Compare tabs needs optional permission and reads up to 20 supported tabs in the current window.
