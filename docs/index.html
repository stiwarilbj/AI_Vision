Privacy and control

Your key stays in Chrome.

AI Vision sends the prompt and the screenshot or page context needed for your request directly to Google’s Gemini API. The full key stays in the extension service worker’s local storage. There is no developer analytics, advertising, or proxy server.

Read the full privacy notice →
  • Only runs when you invoke a feature
  • Panel receives masked key status
  • Restricted Chrome pages stay off limits
  • Browser tasks remain optional and approval-based

Good to know

Questions people ask first.

Do I need a Gemini API key?

Yes. Create one in Google AI Studio, paste it into Settings, and save it. Google controls model access, quotas, and pricing.

What can AI Vision explain?

Ask about a selected screenshot, readable content on the current webpage, or supported pages across up to 20 tabs in one Chrome window.

Can AI Vision read every Chrome page?

No. Chrome internal pages, the Chrome Web Store, and other restricted pages cannot be analyzed.

Does AI Vision control my computer?

Optional Browser tasks stay inside the selected Chrome scope, ask for approval before consequential actions, and cannot control other apps.
